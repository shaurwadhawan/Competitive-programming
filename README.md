# Competitive Programming

This repository contains my solutions to competitive programming and algorithmic problems, organised by topic. It serves as a record of my progress in data structures, algorithms, and problem-solving techniques.

---

## Folder Structure

- arrays/ – prefix sums, sliding window, two-pointer techniques  
- strings/ – pattern matching, hashing, frequency maps  
- graphs/ – BFS, DFS, shortest paths, connected components  
- dp/ – dynamic programming (knapsack, LIS, grid DP, etc.)  
- greedy/ – interval scheduling, sorting strategies, optimisations  
- math/ – number theory, modular arithmetic, combinatorics  

Each folder will contain multiple solved problems, each in its own file.

---

## Goals

- Build a strong foundation in algorithms and data structures  
- Practice solving problems using Python/C++  
- Prepare for competitive programming contests and CS admissions  
- Document learning and improvement over time  

---

## Problem File Format

Each solution file will follow this structure (written as comments at the top of each file):

Problem: <name>  
Topic: <arrays / strings / dp / graph / greedy / math>  
Approach: <2–3 line explanation>  
Time Complexity: O(...)
